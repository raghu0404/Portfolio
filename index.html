INDUSTRIAL AUTOMATION completed

Spring Retention Time Inspection System

Developed an automated spring inspection system using KTP700 Basic, SIMATIC S7-1200 PLC, and Universal Robots UR 5-e cobot.

  • The robot (with EOAT) applies controlled force on the spring
  • PLC measures spring retention time
  • Based on time threshold, spring is classified as OK / NOT OK
  • HMI displays live status, cycle count, and inspection results

Integrated robot–PLC communication and implemented real-time decision logic for quality classification.
